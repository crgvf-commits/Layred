# Experiment 02 — corrected controlled routing comparison

**Synthetic** inputs: seven scenarios and eight scenario–recipient cases. Identical evidence, recipient authorization, N2 qualification and N3 applicability gates are imposed on both policies.

C2: international ingress is N0-mediated, from N0 directly to the authorized destination N1; domestic events are not forced via N0. F1: authorized direct international N1 ingress when assumed available; otherwise same N0 fallback. Authorization and path availability in scenarios are **declared assumptions**, not extracted from the 7,854 public events.

To reproduce outside the master driver, from repository root:

```sh
python -m pip install -r requirements-plot.txt
# The experiment expects its script in the same directory as `dados/`.
mkdir -p local_exp
cp experiment02/scripts/*.py local_exp/
cp -r experiment02/data local_exp/dados
cd local_exp
python rodar_experimento_revisado.py
python testar_resultados.py
```

Expected: 20 vs. 17 directed path-edge **occurrences** across eight pairs, four modeled permitted N3 deliveries per policy, 3 fewer occurrences (15% relative to C2). Counting directed unique links per synthetic scenario gives 19 vs. 16. Disabling all direct paths gives 20 vs. 20. The cumulative figure is generated by the script.

The older 24/17 result is excluded because it imposed unnecessary N0 traversals on the centralized comparator. These are logical path lengths, not measured runtime, MISP traffic or link utilization. Reviewers may edit `dados/cenarios_controlados.json` and assumptions to investigate alternative contexts, but the experiment file contains fixed numeric regression checks that should be adjusted for *new* scenarios.
